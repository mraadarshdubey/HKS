## 🚀 Overview

Welcome to the **Digital HQ** of Kiran Hajare. This repository hosts a high-converting, premium React web application designed to serve as a comprehensive branding and lead-generation funnel. Built with an architecture optimized for speed, visual authority, and seamless user experience.

## 💎 Key Highlights & Aesthetics

- **Premium Dark Mode:** Deep "brand black" (`#050505`) combined with luxurious gold accents (`#cf9d45`).
- **High-Converting Funnel:** Strategic CTA placements, sticky mobile actions, and immersive video integration.
- **Multi-Page Hub:** Powered by `react-router-dom` for an expansive content ecosystem (My Story, Podcasts, Books, Mission, Press, etc.).
- **Immersive Micro-Interactions:** Custom hover states, grayscale-to-color transitions, and ambient background glow effects.
- **Flawless Responsiveness:** Custom structural logic ensuring a pixel-perfect experience from ultra-wide monitors down to mobile screens.

```text

├── components/       # Reusable UI blocks (Hero, Footer, Navbar, CTAs)
├── pages/            # 14+ Custom Subpages (Mission, Story, Podcasts, etc.)
├── hooks/            # Custom logic hooks
├── index.css         # Global design system & animation tokens
└── App.jsx           # Core routing configuration
```

## 🏎️ Quick Start

To experience the premium funnel locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/mrradarsh/HKS.git
   cd HKS/HKS-React
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Ignite the Development Server**
   ```bash
   npm run dev
   ```
   *Your server will start at `http://localhost:5173/`*

## 🎨 Design Philosophy

Our UI/UX philosophy is centered around **Trust, Authority, and Action**. 
- **Typography:** `Syne` for authoritative, modern headlines. `Inter` for clean, highly readable body copy.
- **Layout:** Grid-based precision with glassmorphism overlays and ambient light diffusion.
